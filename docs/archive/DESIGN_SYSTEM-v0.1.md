# DanceMirror Design System

## 1. 视觉关键词

- 镜面
- 舞房
- 成长
- 复盘
- 出片
- 轻量教练感

整体风格年轻、干净、轻运动、偏女性友好，但避免廉价粉色和过度可爱。

首屏必须是用户可操作的双视频逐帧比对工作台，而不是宣传海报或落地页。老师视频、用户视频、时间轴、红绿路径标注和 AI 比对状态要成为第一视觉重点。

## 2. 色彩

基础色：

- Ink：`#111113`
- Text：`#242428`
- Muted：`#6f7178`
- Border：`#e6e7eb`
- Surface：`#ffffff`
- App background：`#f7f8fa`

强调色：

- Electric cyan：`#13c8ff`
- Soft coral：`#ff5a7a`
- Fresh lime：`#b7f34a`

使用原则：

- 大面积保持黑白灰，强调色只用于关键按钮、进度、AI 标签和高亮信息。
- 不使用大面积紫色渐变、土色、深蓝背景。
- 报告卡片可以用轻微色块区分，但不要做厚重装饰。

## 3. 字体与排版

- 优先使用系统字体。
- 标题清晰有力，正文保持可读。
- 移动端最小正文字号 14px。
- 不使用随视口无限放大的字体。
- 数字评分可以略大，但不要让评分压过建议内容。

## 4. 组件

按钮：

- 主按钮：黑底白字，8px 圆角以内
- 次按钮：白底黑字，细边框
- 危险/删除：只在必要时出现

卡片：

- 只用于重复内容、报告模块、上传视频预览
- 圆角不超过 8px
- 避免卡片套卡片

上传区：

- 明确区分「老师示范」和「我的练习」
- 上传后展示视频预览、文件名、删除按钮
- 第一屏必须能并排上传/预览两段视频，不使用大标题海报式首屏

比对标注：

- 绿色线表示老师/标准动作路径
- 红色线表示用户偏离路径
- 每次比对后必须生成 AI 总结，并保存到历史记录

报告：

- 先展示总反馈，再展示 3 个关键问题
- 每个问题都要有时间点、差异、原因、练习建议
- 适合截图分享，但不要牺牲可读性

## 5. 文案语气

像舞蹈老师，不像考试系统。

推荐：

- 「这一遍最大的问题是重心没有跟上手部动作」
- 「先不要急着练整段，今天只抓 8 秒到 12 秒」
- 「这条裤子会遮住膝盖方向，如果要复盘腿部动作，建议换更清晰的版型」

避免：

- 「动作错误」
- 「不合格」
- 「得分低」
- 「请提升动作完成度」
